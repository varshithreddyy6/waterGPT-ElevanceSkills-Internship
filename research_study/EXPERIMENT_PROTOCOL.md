# Experiment protocol

## Primary benchmark
Official BEIR SciFact test split only: full supplied corpus, queries, and `qrels/test.tsv`. The qrels are used solely for held-out evaluation. No parameter selection is performed on this split. Dataset files and checksums are recorded before execution.

## Fixed main configuration
BM25Okapi (`k1=1.5`, `b=0.75`); common lowercased regex tokenization; title plus abstract/text; dense model `sentence-transformers/all-MiniLM-L6-v2`; normalized float32 vectors; exact FAISS `IndexFlatIP`; candidate retrieval depth 1,000; RRF k=60; deterministic lexical doc-ID tie-break and RRF doc-ID tie-break. Every qrel test query is evaluated. Test queries with no positive judgments remain in macro denominators with zero metrics, following explicit evaluator behavior.

## Execution and timing
Embedding/document/index build are reported separately from query latency. Query retrieval is single-query (not batched); warm-up queries are excluded from latency summaries. Repeated timing runs report mean, median, and p95. CPU/GPU, OS, Python and key package versions are recorded. GPU is opt-in; CPU is the default.

## Metrics and inference
Macro query-level nDCG@10, MRR@10, Recall@10, Recall@100. Recall treats all positive qrel documents as relevant; nDCG uses graded gains `2^rel-1`. Paired bootstrap uses 10,000 resamples and a fixed seed. Paired Wilcoxon signed-rank tests are accompanied by Holm correction across method comparisons for each outcome. Statistical claims require uncertainty and practical magnitude discussion.

## Ablations
RRF k in {20,60,100}, candidate depth {100,500,1000}, title-only versus title+abstract. These are descriptive test-set ablations, not tuning or model selection. They must not replace the fixed primary result.

## Reproducibility
All outputs are generated by CLI, with runfiles, per-query scores, environment metadata and configs preserved. Do not commit the raw corpus or model caches. Results are valid only if all official queries and relevant IDs validate and tests pass.
